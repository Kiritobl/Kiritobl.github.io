简介

C++ 是一门强大的编程语言，广泛应用于系统编程、游戏开发、高性能计算等领域。本文将介绍 C++ 的基础知识，帮助初学者快速入门。

基本语法

1. Hello World 程序

让我们从最经典的 Hello World 程序开始：

#include <iostream>

int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}

2. 变量和数据类型

C++ 提供了多种基本数据类型：

  • int - 整数类型
  • double - 双精度浮点数
  • char - 字符类型
  • bool - 布尔类型
  • string - 字符串类型（需要包含 <string> 头文件）
int age = 25;
double price = 19.99;
char grade = 'A';
bool isStudent = true;
std::string name = "Kirito";

3. 控制结构

C++ 支持常见的控制结构：

条件语句：

if (age >= 18) {
    std::cout << "成年人" << std::endl;
} else {
    std::cout << "未成年人" << std::endl;
}

循环语句：

// for 循环
for (int i = 0; i < 5; i++) {
    std::cout << i << " ";
}

// while 循环
int count = 0;
while (count < 5) {
    std::cout << count << " ";
    count++;
}

函数

函数是 C++ 中组织代码的基本单位：

// 函数定义
int add(int a, int b) {
    return a + b;
}

// 函数调用
int main() {
    int result = add(5, 3);
    std::cout << "5 + 3 = " << result << std::endl;
    return 0;
}

总结

本文介绍了 C++ 的基础知识，包括基本语法、变量、控制结构和函数。这些是学习 C++ 的基础，掌握这些内容后，你可以继续学习更高级的特性，如类、指针、模板等。
