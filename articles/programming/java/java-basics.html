简介

Java 是一种广泛使用的面向对象编程语言，以其"一次编写，到处运行"的特性而闻名。本文将介绍 Java 的基础知识，帮助初学者快速入门。

Java 的特点

  • 跨平台：通过 JVM（Java 虚拟机）实现跨平台运行
  • 面向对象：完全面向对象的编程语言
  • 自动内存管理：垃圾回收器自动管理内存
  • 丰富的类库：强大的标准库支持
  • 安全性：内置安全机制

第一个 Java 程序

Hello World

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

编译和运行：

javac HelloWorld.java  // 编译
java HelloWorld        // 运行

基本语法

1. 变量和数据类型

Java 是强类型语言，变量必须先声明后使用：

基本数据类型：

// 整数类型
byte b = 100;        // 8位
short s = 10000;     // 16位
int i = 100000;      // 32位
long l = 100000L;    // 64位

// 浮点类型
float f = 3.14f;     // 32位
double d = 3.14159;  // 64位

// 字符和布尔类型
char c = 'A';        // 16位 Unicode 字符
boolean flag = true; // true 或 false

引用类型：

String name = "张三";
String[] names = {"张三", "李四", "王五"};
Integer num = 42;  // 包装类

2. 运算符

// 算术运算符
int sum = 5 + 3;      // 加
int diff = 5 - 3;     // 减
int product = 5 * 3;  // 乘
int quotient = 5 / 3; // 除
int remainder = 5 % 3;// 取模

// 比较运算符
boolean isEqual = (5 == 3);  // false
boolean isGreater = (5 > 3); // true

// 逻辑运算符
boolean and = true && false;  // 与
boolean or = true || false;   // 或
boolean not = !true;          // 非

3. 控制流程

if-else 语句：

int score = 85;

if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 80) {
    System.out.println("良好");
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}

switch 语句：

int day = 3;
String dayName;

switch (day) {
    case 1:
        dayName = "星期一";
        break;
    case 2:
        dayName = "星期二";
        break;
    case 3:
        dayName = "星期三";
        break;
    default:
        dayName = "其他";
}

循环语句：

// for 循环
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

// while 循环
int count = 0;
while (count < 5) {
    System.out.println(count);
    count++;
}

// do-while 循环
int num = 0;
do {
    System.out.println(num);
    num++;
} while (num < 5);

// 增强 for 循环（for-each）
int[] numbers = {1, 2, 3, 4, 5};
for (int n : numbers) {
    System.out.println(n);
}

面向对象基础

类和对象

public class Person {
    // 成员变量
    private String name;
    private int age;
    
    // 构造方法
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
    
    // Getter 和 Setter
    public String getName() {
        return name;
    }
    
    public void setName(String name) {
        this.name = name;
    }
    
    public int getAge() {
        return age;
    }
    
    public void setAge(int age) {
        this.age = age;
    }
    
    // 成员方法
    public void introduce() {
        System.out.println("我是 " + name + "，今年 " + age + " 岁。");
    }
}

// 使用
Person person = new Person("小明", 25);
person.introduce();

方法

方法定义和调用

public class Calculator {
    // 无返回值的方法
    public void printSum(int a, int b) {
        System.out.println("和为：" + (a + b));
    }
    
    // 有返回值的方法
    public int add(int a, int b) {
        return a + b;
    }
    
    // 方法重载
    public int add(int a, int b, int c) {
        return a + b + c;
    }
    
    public double add(double a, double b) {
        return a + b;
    }
}

// 使用
Calculator calc = new Calculator();
calc.printSum(5, 3);
int result = calc.add(5, 3);

异常处理

try {
    int result = 10 / 0;  // 会抛出异常
} catch (ArithmeticException e) {
    System.out.println("除数不能为零！");
    e.printStackTrace();
} finally {
    System.out.println("清理资源");
}
