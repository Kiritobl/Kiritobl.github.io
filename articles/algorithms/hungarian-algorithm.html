目标

在二分图中找到完美匹配（最大匹配）。

基本思想

匈牙利算法的本质是"贪心 + 回溯"：为每个未匹配顶点尝试寻找增广路径，若当前路径不可行则回溯调整已匹配顶点的连接关系。

核心逻辑：对 U 集中每个顶点依次执行"找增广路径"操作，每找到一条增广路径，匹配边数就增加 1，直至遍历所有顶点。

核心概念

二分图

二分图 \(G=(X,Y,E)\)：

  • \(X\) 是左侧顶点集
  • \(Y\) 是右侧顶点集
  • \(E\) 是边集

饱和顶点与非饱和顶点

  • 饱和顶点：在匹配 \(M\) 中被包含的顶点（有对应匹配边）
  • 非饱和顶点：未被包含的顶点

邻域

\(N(S)\)：集合 \(S\)（\(X\) 的子集）的"邻域"，即与 \(S\) 中顶点直接相连的 \(Y\) 中顶点的集合。

对称差集

\(M \Delta E(P)\)：匹配 \(M\) 与增广路径 \(P\) 的边集的对称差集。

简单说：删除 \(P\) 中已在 \(M\) 的边，添加 \(P\) 中不在 \(M\) 的边，实现匹配扩展。

Hall 定理

定理（Hall 定理）

设 \(G=(X, Y)\) 是偶图，则 \(G\) 存在饱和 \(X\) 每个顶点的匹配的充要条件是：

对 \(X\) 的任意子集 \(S\)，都有 \(|N(S)| \ge |S|\)

这个定理为判断二分图是否存在完美匹配提供了理论依据。

算法实现

匈牙利算法步骤

初始化：以任一匹配 \(M\) 作为开始（可取 \(M=\emptyset\)）

a) 判断是否完美匹配

  • YES：停止，\(M\) 为完美匹配
  • NO：取 \(X\) 中 \(M\) 非饱和顶点 \(u\)，置 \(S=\{u\}\)，\(T=\emptyset\)，转到 b)

b) 判断邻域条件

  • 判断是否 \(N(S)=T\)？
  • YES：停止，根据 Hall 定理，\(G\) 中不存在完美匹配（当前找到的为最大匹配）
  • NO：否则设 \(y \in N(S) - T\)，转到 c)

c) 判断饱和状态

  • 判断 \(y\) 是否为 \(M\) 饱和点？
  • YES：设 \(yz \in M\)，置 \(S=S \cup \{z\}\)，\(T=T \cup \{y\}\)，转 b)
  • NO：设 \(u\) 到 \(y\) 为 \(M\) 的可扩路 \(P\)，置 \(M_1=M \Delta E(P)\)，转 a)

算法要点

  • 步骤 b) 和 c) 的过程实际上是在寻找可扩展路径的操作
  • 每次引入 \(S\)、\(T\) 的操作其实就是拓展路径延伸的操作
  • 通过不断调整已匹配的边，尝试为新顶点找到匹配
  • 如果无法找到增广路径，则当前匹配为最大匹配

Python 实现

def hungarian_algorithm(graph):
    """
    匈牙利算法实现二分图最大匹配
    
    参数:
        graph: dict, 邻接表表示的二分图 {u: [v1, v2, ...]}
    
    返回:
        match: dict, 匹配结果 {右顶点: 左顶点}
    """
    match = {}  # 右侧顶点的匹配
    
    def dfs(u, visited):
        """深度优先搜索寻找增广路径"""
        for v in graph.get(u, []):
            if v not in visited:
                visited.add(v)
                # 如果 v 未匹配或者能为 v 的匹配找到新的匹配
                if v not in match or dfs(match[v], visited):
                    match[v] = u
                    return True
        return False
    
    # 对每个左侧顶点尝试找增广路径
    for u in graph:
        visited = set()
        dfs(u, visited)
    
    return match


# 示例使用
if __name__ == "__main__":
    # 构建二分图：左侧顶点 -> 右侧顶点列表
    bipartite_graph = {
        'A': [1, 2, 3],
        'B': [1, 4],
        'C': [3, 4],
        'D': [2, 4]
    }
    
    result = hungarian_algorithm(bipartite_graph)
    print("匹配结果：")
    for right, left in result.items():
        print(f"  {left} -> {right}")
    
    print(f"\n最大匹配数：{len(result)}")

时间复杂度

  • 最坏情况：\(O(VE)\)，其中 \(V\) 是顶点数，\(E\) 是边数
  • 对于每个左侧顶点，可能需要遍历所有边来找增广路径
  • 通过优化可以达到 \(O(\sqrt{V}E)\)（使用 Hopcroft-Karp 算法）

应用场景

  • 任务分配问题：将 n 个任务分配给 m 个工人
  • 婚姻匹配问题：n 个男生和 m 个女生的配对
  • 资源调度：时间槽分配、教室安排等
  • 网络流问题：作为最大流算法的特例

总结

匈牙利算法通过不断寻找增广路径来扩展匹配，是解决二分图最大匹配问题的经典算法。理解其核心思想（贪心+回溯）和 Hall 定理，有助于深入掌握图论中的匹配问题。

关键点回顾

  • 增广路径是匹配数增加的关键
  • Hall 定理提供了完美匹配存在的充要条件
  • DFS 是寻找增广路径的常用方法
  • 算法的正确性基于增广路径定理
